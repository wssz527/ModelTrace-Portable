# 安装连接扩展

1. 解压 ZIP，将 `ModelTrace-连接扩展` 文件夹放到固定位置。
2. Edge 地址栏打开 `edge://extensions`；Chrome 地址栏打开 `chrome://extensions`。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择包含 `manifest.json` 的 `ModelTrace-连接扩展` 文件夹。
5. 打开扩展详情，开启“允许访问文件网址”。
6. 在同一个浏览器中刷新 ModelTrace HTML，点击“检测并继续”。
7. 确认 API 地址，点击“允许连接”。

## 安装检查

- “扩展可用”：填写 API 地址和密钥，拉取模型。
- “通过浏览器扩展已连接”：选择模型，开始测试。
- “未检测到扩展”：检查扩展已启用、文件访问已开启，然后刷新 HTML。
- 如需取消连接，点击 HTML 中的“断开扩展连接”。

请在安装扩展的桌面 Edge / Chrome 中打开 HTML。保留扩展文件夹。
